# GameShelf

Консольная программа для учёта коллекции видеоигр. Данные сохраняются в базе SQLite.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки устанавливать не требуется.

```bash
python main.py
```

При запуске рядом с программой создаётся файл `gameshelf.db`.

## Возможности

- добавление и просмотр игр;
- поиск по названию, платформе и жанру;
- сортировка списка;
- изменение данных игры;
- перемещение записей в архив и восстановление;
- окончательное удаление записей из архива;
- просмотр статистики коллекции.

## Файлы

- `main.py` — меню и ввод данных;
- `database.py` — работа с базой данных;
- `gameshelf.db` — файл базы данных, создаётся при запуске.
